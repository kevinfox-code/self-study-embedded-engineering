# Contributing

## Purpose

This repository documents a self-study embedded engineering curriculum and related project artifacts.

## Contribution Standards

- Keep filenames consistent with repository naming conventions in README.md.
- Prefer ASCII-safe filenames and avoid special Unicode punctuation in file names.
- Maintain clear, factual technical writing and avoid ambiguous claims.
- Do not add third-party copyrighted materials unless distribution rights are confirmed.

## AI Transparency Requirement

If a contribution is generated or substantially drafted by AI (including Claude), include a short note in the pull request or commit message indicating AI assistance.

Example: `AI-assisted: initial draft generated with Claude, validated and edited by maintainer.`

## Licensing Checklist

Before committing:

- Confirm added content is original, public domain, or licensed for redistribution.
- Preserve required attributions for any reused material.
- Avoid embedding proprietary PDFs, paywalled content, or copied textbook chapters.

## Pull Request Checklist

- Naming follows project conventions.
- Content is accurate and reviewed.
- Licensing and attribution are clean.
- AI-assistance disclosure is included when applicable.
